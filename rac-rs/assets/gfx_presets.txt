# Graphics presets of RAC-RS: Low, Medium and High.
#
# THIS IS THE ONE PLACE the values live. The game reads this file (built into the program: retail/pcext/presets.rs, include_str!) for
# the Preset row of Pause -> Options -> Graphics, and the RAC-RS Launcher shows the same three presets on its Settings page. When the
# launcher should read the table from an install instead of its own copy, it is this file, assets/gfx_presets.txt of the rac-rs sources
# (copy it next to the game when you pack a release). Edit the values here only; a test checks that High is the game's default picture.
#
# Format: one `<preset>.<key>=<value>` per line, `#` starts a comment. Presets: low, medium, high. Keys and values are those of
# pc_options.txt: lighting classic|enhanced, draw low|medium|high, smoothing on|off, hud sharp|original, ao / shadows / sunrays / gi
# off|low|medium|high, water / particles classic|low|medium|high, vegetation off|moderate|lush, waves on|off, fog / clouds classic|low|medium|high, texfilter classic|smooth (only active with Lighting Enhanced).
#
# Never part of a preset: camera, controls, language, display mode, the renderer (Vulkan / DirectX 12), debug mode. Every preset sets Culling On
# (v0.4.1; not a table key, so the launcher's table is unchanged).
